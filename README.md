### Assignment-01: Bank Management System (Mini Project)
A menu-driven Python program that simulates basic banking operations.

- Withdraw money (with balance check)
- Check account balance
- Exit with a thank-you message

**Concepts used:** Functions, `while` loop, `if-else` conditions (no external libraries)

📄 File: [`Assignment-01/bank_management.py`](./Assignment-01/bank_management.py)

### Assignment-02: Data Analysis (Mean, Median, Mode)
A Python program that accepts a list of numbers from the user and calculates statistical measures.

**Features:**
- Mean calculation
- Median calculation (handles both odd and even-sized datasets)
- Mode calculation (handles single mode, multiple modes, or no mode)

**Concepts used:** Lists, loops, functions (no `statistics` or `numpy` libraries)

📄 File: [`Assignment-02/data_analysis.py`](./Assignment-02/data_analysis.py)
